# Scent Science Questionnaire

A self-marking questionnaire on detection dog training: green dog selection, target odor imprinting, headspace and molecular mass, how odor moves and ages, theories of olfaction, surface area, drug, explosive and cadaver odors, training aids, and signal dogs.

**Take it:** https://sydrouxba5.github.io/scent-science-quiz/

## How it works

- 65 questions across 12 topics, written from two class lectures and 62 slides.
- Run everything, drill one topic, or retry only the questions you missed.
- Every answer comes with a short explanation and the lecture or slide it came from.
- "See all questions and answers" gives the full answer key, which can be printed.
- Progress is saved in your own browser only. Nothing is sent anywhere, and there are no cookies or trackers.

Answers follow what was taught in class. Where a point is the instructor's own view, the explanation says so.

## Editing the questions

All questions live in `questions.js`. In a multiple-choice question the first option is the correct one (the page shuffles them). True/false questions use `tf: true` or `tf: false`. The page is plain HTML, CSS and JavaScript with no build step: open `index.html` to run it locally.
